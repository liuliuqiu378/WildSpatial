> 功耗用「相对算力预算」代理（需 root 可 sudo 读 intel-rapl 换绝对瓦数）；延迟/精度为直接实测，与架构无关，可反映端侧趋势。
> **关键发现**：可行域是一个**窗口**而非连续旋钮——0.5x ORB1000 是性价比最佳点（且 ATE 优于全分辨率 SIFT）；一旦越过「特征地板」(ORB<~1000)或「分辨率悬崖」(<0.5x)，VO 直接初始化失败而非平滑退化。这正是端侧必须配 M3 失效预警、校准集须覆盖退化的原因。
