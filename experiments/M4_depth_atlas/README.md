# M4 深化 · VGGT 深度 / 点云质量失效图谱

**序列**：fr1/desk（60 帧）

## 目的
M5 只比了轨迹 ATE；本实验用 VGGT 的稠密深度 / 世界点，在 13 退化条件下量化「几何重建质量」是否也随退化崩坏。

## 方法
VGGT(return_dense) 直接出深度图与 world_points；深度用中位比例与真值对齐后算 RMSE/AbsRel/δ1；world_points 借相机中心轨迹的 Sim3 对齐到真值系，与真值点云算 Chamfer。
