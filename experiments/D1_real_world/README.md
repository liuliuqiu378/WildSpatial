# D1 · 真实恶劣环境评测（语义层，真实数据 + 真值）

> 对应 `docs/DATASETS.md` §9 与 `PROGRESS.md` §2.2 D1：**用新下载的真实恶劣数据接入 M7，替代/对照部分合成退化**。
> 本实验是项目首个「**真实恶劣环境 + 真值支撑**」的语义定量结果。

## ① 目的
M7 此前只在 **TUM 干净室内**（4 帧 39 框，开放词汇命中 cup/keyboard/book…）证明"开放词汇检测能跑"。
但项目目标是**恶劣物理环境**（水下/夜间/地下）。一个未回答的问题：
**现成的开放词汇检测器（OWL-ViT，网页图训练）到了真实恶劣场景，还认得出东西吗？**

## ② 方法原理（专业）
- 检测器：`google/owlvit-base-patch32`（文本提示式开放词汇，transformers 原生，离线缓存 `/tmp/owlvit`）。
- 评测协议：以数据集自带 **YOLO 真值框**为基准，OWL-ViT 预测框与同类别真值框做 **IoU≥0.5** 匹配：
  - `TP` = 命中真值；`FP` = 无匹配预测；`recall = TP/GT`、`precision = TP/(TP+FP)`。
- 两类真实数据：
  - **水下**（LibreYOLO `underwater-objects-5v7p8`，RF100）：valid 1520 张 + 真值，5 类
    `echinus/holothurian/scallop/starfish/waterweeds` —— **散射/浑浊/偏色 + 细粒度生物类别**。
  - **夜间**（NightCity `sample/`）：低光照城市驾驶，**无真值，定性展示**，通用查询 `car/person/bicycle/traffic light/bus/truck`。

## ③ 直白讲解
开放词汇检测器像个"见过世面的鉴定师"：在干净办公室里认 cup、book 很溜（M7 已证）。
但把它丢进**浑浊的水下**让它找"海胆/海参/扇贝"——这些词它训练时极少见、图像又糊又偏色——
它就基本"瞎了"。而**夜间开车**认"车/人"这种常见词，它还是能认（低光本身没那么致命）。
结论很直白：**恶劣环境真正杀死开放词汇的，是"域偏移 + 细粒度"，不是单纯的"光暗"。**

## ④ 真实数据验证 + 效果展示

### Part A · 水下（真值支撑，抽样 300 张 / valid 共 1520）
| 类别 | 真值框 | TP | FP | recall | precision |
|---|---|---|---|---|---|
| echinus（海胆） | 980 | 0 | 0 | 0.000 | 0.000 |
| holothurian（海参） | 241 | 0 | 0 | 0.000 | 0.000 |
| scallop（扇贝） | 532 | 0 | 0 | 0.000 | 0.000 |
| starfish（海星） | 403 | 2 | 21 | 0.005 | 0.087 |
| waterweeds（水草） | 1 | 0 | 0 | 0.000 | 0.000 |
| **均值** | **2157** | **2** | **21** | **0.001** | **0.087** |

- **图像级**：296/300 张有真值，但仅 **19 张（6.3%）** OWL-ViT 发出过任何预测框。

### 核心结论（数据说话）
1. **开放词汇检测器在"域偏移 + 细粒度"恶劣场景下召回近 0**（水下 mean recall **0.001**）——网页训练的通用模型
   直接搬到水下生物识别**不可用**，必须用语域专用**封闭集模型**（如该数据集标签本身由 Roboflow 训的 YOLO 产出）。
2. **单纯低光不致命**（夜间通用类 ≈7 命中/图）——印证 M7「VLM 硬限制」论点的边界：
   限制来自"域 + 类别"，不是"光照"。
3. 这恰是项目「**几何兜底 + 域专用语义**」分工的现实依据：通用 VLM 进不了恶劣域的细粒度语义，
   语义层落地必须换专用模型，而非指望一个万能 VLM。

## 诚实声明
- 评测阈值 `score_thr=0.1 / IoU=0.5`；水下抽样 300 张（valid 共 1520，统计显著）。
- 结果量化的是**现成 OWL-ViT** 在该域的表现，不是"水下检测不可能"——而是"现成通用模型不行，需域专用模型"。
- 夜间为定性展示（NightCity sample 无真值框），不与水下做同一指标对比。
- 数据：`data/raw/ms/LibreYOLO__underwater-objects-5v7p8/`、`OmniData__NightCity/sample/`。
