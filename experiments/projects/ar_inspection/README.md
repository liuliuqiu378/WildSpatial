# 实战项目：AR 设备端实时解构（无需下载）

> 知识落点（M0–M9 → 实战）：用程序生成的『绕圈相机+彩色物体+已知位姿』序列，零下载验证整套整合层：VO 重建→深度定尺度→场景图解构→端侧预算。证明框架与数据来源解耦，任何新数据集只要能归一成 Sequence，就能立刻接入全部 M0–M9 工序。

**数据集**：程序合成序列（无需下载，演示无网环境也能跑通框架）  
**序列规模**：100 帧 | 场景标签 `synthetic` | 深度=有 | 真值=有
