# M2 深度重建（Open3D TSDF 融合，现成工具）

**序列**：fr1/desk（60 帧融合，体素 0.01m）

## 目的
用现成工具 Open3D 的 TSDF 融合，把真实深度图 + 真值位姿一键重建成 3D 网格，建立「深度→几何」的直观认知，而非手搓融合数学。

## 方法原理
TSDF（截断符号距离场）把每帧深度反投影成空间点的有向距离，多视角融合取平均得到平滑表面，再 Marching Cubes 提取网格。

## 直白讲解
就像把很多张带深度的照片「糊」进同一个 3D 体素格子，离表面近的地方填满、远的地方空着，最后把「刚好填满的边界」描成网格。
