# P2 · 动态障碍完整工程 demo（仿真→感知→决策→控制）

> 把 P1（动态避障）与 P2（感知实验台）串成**完整工程闭环**——各维度数据的利用。

## ① 五层数据流

```
Gazebo 世界（2 个真实物理运动的行人）
   ├─ ① 传感层：相机 RGB / LiDAR 扫描 / 真值位姿
   ├─ ② 感知层：算出『行人相对距离』
   ├─ ③ 决策层：距离 < 1.0m → 减速避让
   ├─ ④ 控制层：输出 cmd_vel (v, ω)
   └─ ⑤ 物理反馈：Gazebo 推进 → 闭环
```

![五层数据流](figs/pipeline.png)

## ② 实测结果

- 闭环步数：**735**
- 触发避让：**562 步**
- 最近行人距离：**1.126 m**
- 动态行人数量：**2**

## ③ 与 P1 的区别

| | P1 | 本 demo |
|---|---|---|
| 行人 | 脚本模拟匀速直线 | **Gazebo 真实物理体（有质量/碰撞）** |
| 感知 | 直接读模拟坐标 | **真实传感器（相机/LiDAR）+ 真值位姿** |
| 闭环 | 离线路径 → 指令 | **在线：感知→决策→控制→物理反馈** |

## ④ 直白讲解

**这是机器人真正的『感知-决策-控制』心跳**：
传感器（眼睛）→ 感知（看懂有人在前面）→ 决策（太近了要停）→ 控制（踩刹车/转向）→ 世界变了（闭环）。

## ⑤ 诚实边界

- 行人位置读自**仿真真值**（Pose_V）；真实系统需用**检测+跟踪**得到（本项目 M7 方向）。
- 行人为无摩擦滑行（约 5 秒穿过视野），演示足够。
