# P2 · 动态障碍完整工程 demo（仿真→感知→决策→控制）

> 把 P1（动态避障）与 P2（感知实验台）串成**完整工程闭环**——各维度数据的利用。

## ① 五层数据流

```
Gazebo 世界（2 个真实物理运动的行人）
   ├─ ① 传感层：相机 RGB / LiDAR 扫描 / 真值位姿
   ├─ ② 感知层：算出『行人相对距离』
   ├─ ③ 决策层：距离 < 1.0m → 减速避让
   ├─ ④ 控制层：输出 cmd_vel (v, ω)
   └─ ⑤ 物理反馈：Gazebo 推进 → 闭环
```

## ③ 与 P1 的区别

| | P1 | 本 demo |
|---|---|---|
| 行人 | 脚本模拟匀速直线 | **Gazebo 真实物理体（有质量/碰撞）** |
| 感知 | 直接读模拟坐标 | **真实传感器（相机/LiDAR）+ 真值位姿** |
| 闭环 | 离线路径 → 指令 | **在线：感知→决策→控制→物理反馈** |

## ④ 直白讲解

**这是机器人真正的『感知-决策-控制』心跳**：
传感器（眼睛）→ 感知（看懂有人在前面）→ 决策（太近了要停）→ 控制（踩刹车/转向）→ 世界变了（闭环）。

## ⑤ 诚实边界

- 行人位置读自**仿真真值**（Pose_V）；真实系统需用**检测+跟踪**得到（本项目 M7 方向）。
- 行人为无摩擦滑行，**由脚本做边界反射使其场内往复**（y∈±3.0m，0.35 m/s）——
  见下方「动图闭环」的修复记录；若不干预，恒速行人会撞墙穿透并卡死。

## ⑥ 动图闭环（`p2_dynamic_obstacle_gif.py`）

![闭环动图](figs/closed_loop.gif)

> 俯视全景回放：机器人**朝紫星（当前目标点）前进**（蓝色朝向箭头指向它），
> 到达后紫星跳到下一航点；红圆是**往复穿行的行人**，橙圈是危险半径，
> 状态框实时显示 `前往目标/避让/绕行后回归目标`。

**🐛 修复记录一：行人"跳来跳去"（用户反馈驱动）**

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 行人 y 范围 | −4.68 ~ 4.68（贴墙） | **±3.0（场内）** |
| 越界（\|y\|>4.9） | 常态发生 | **0 次** |
| 单步位移 | 瞬移 2.7m | **平滑 ~0.35 m/s** |
| 卡死 | t≈5s 后完全静止 | **持续往复，从不静止** |

**根因**：世界行人只有恒速、无边界逻辑 → `mu=0` 零摩擦滑到外墙 → **穿透瞬移** → 卡死贴墙。
**修复**：脚本按真值位置做**边界反射**，`|y|>3.0` 即向 `/model/<name>/cmd_vel` 发反向速度。

**🐛 修复记录二：目标点形同虚设（用户追问"没有朝着五角星前进"）**

| | 旧版（错误） | 新版（修复） |
|---|---|---|
| 控制律 | 跟**环线解析切线**（时间函数），**根本没用 goal** | **`atan2(goal − robot)` 直接朝目标** |
| 目标来源 | `patrol_target(t+1)`，与机器人无关 | **固定航点表** `WAYPOINTS[wp_idx]` |
| 到达行为 | 无 | 距目标 <0.28m → **切换下一航点** |

**本质错误**：混淆**轨迹跟踪**（跟切线）与**目标点导航**（朝目标）两个范式 —— 写了前者却画了后者的目标点。
**实测验证**：**朝向误差中位数 0.1°**（巡航几乎完美对准目标）；
均值 26.3° 是被**避让帧**拉高（避让时故意偏转 63°，自洽）；
到目标距离周期收敛至 0.28m 后跳走（到达圈生效）；目标点跳变 11 次。

**❓ "目标点在动是在追踪吗？"** —— **不是追踪**。它是**巡逻路线上当前要去的航点**；
到达即切换（紫星"跳"过去）。机器人**确实朝它走**（朝向箭头 + HUD 朝向误差可验证）。
