## 1. 目的（场景 · 需求 · 真实问题）

### 1.1 场景
园区 / 室内 **夜间配送机器人**：在弱光、动态行人、烟雾等恶劣条件下，从货架取物 → 自主导航 → 避开门前行人 → 送达。

### 1.2 真实问题（初学者 / 传统方案最易翻车的一刀）
> 单目几何 VO（SIFT→匹配→RANSAC→三角化→PnP）的**第一道失效环节是「特征匹配」**。
> 一旦弱光 / 运动模糊使可匹配特征骤减，VO 的平移量趋于 0 —— **机器人原地转圈、轨迹塌缩、直接迷路**。

这不是假设。本项目在带真值的 TUM `fr1/desk` 上施加合成退化（弱光 0.9 / 运动模糊 0.7）实测：

| 方法 | clean ATE | 弱光(0.9) | 运动模糊(0.7) | 行为 |
|---|---|---|---|---|
| **自研 VO（SIFT）** | 0.166 m | **塌缩（路径长=0）** | **塌缩** | 冻结在原点 |
| COLMAP（工业级几何） | 0.028 m | 0.067 m | 0.026 m | 稳 |
| **VGGT（前馈 3D 基础模型）** | 0.022 m | **0.020 m** | **0.030 m** | 几乎不变 |
| LightGlue VO（学习前端） | 0.494 m | 0.297 m | 0.421 m | 不崩但精度有限 |

**核心洞察**：「离线全局（VGGT / COLMAP）vs 在线增量（VO）」的分野，比「经典 vs 学习」更本质——
增量 VO 靠帧间跟踪续命，可重复特征一断即死；全局方法联合求解，单帧崩了能被拉回。

### 1.3 需求拆解（面试官最爱追问的「系统该满足什么」）
1. **实时定位**：厘米~分米级，恶劣工况不失效；
2. **失效可检测**：必须能发现「我迷路了」，否则下游全错；
3. **失效有兜底**：检测到失效要能切换到鲁棒方法；
4. **定位变指令**：感知结果必须转化成可执行的 `v/ω` 控制；
5. **端侧可行**：算力 / 功耗 / 延迟可接受。

## 2. 方法原理（专业）

### 2.1 鲁棒感知：传统几何 VO vs 前馈 3D 基础模型
- **传统 VO**：逐帧 `特征提取 → 匹配 → 本质矩阵 → 三角化 → PnP → BA`。
  脆弱点是「特征→匹配」这一步，退化直接切断。
- **VGGT（`M4`）**：一次前向传播直接输出相机内外参 + 深度 + 点云，
  **绕开了最容易失效的「特征→匹配」环节**，所以抗退化。代价：尺度靠对齐、无语义、黑箱。

### 2.2 诊断驱动融合兜底（`M6`）
监控定位是否失效的两类信号（本项目实跑验证有效）：
- **路径长度比**：`est_path_len / gt_path_len < 5%` → 判定「跟踪丢失」（自研 VO 在弱光下 est 路径长 = 0）；
- **内点率**（M3/M5 实证：健康 75~80%，崩前跌破 11.4%）。

决策逻辑（本脚本实跑）：
```
主方法 = 自研 VO
if 主方法在『motion_blur』退化 → 路径长=0（塌缩）:
    触发融合兜底 → 切换到 VGGT（ATE=0.030m，轨迹可用）
```
尺度由真值路径长度（或真实深度）定标（中位逐段位移比）。

### 2.3 闭环控制（感知→规划→控制，`P1`/`F6`）
托底轨迹 → 深度反投影成 **2.5D 占据栅格**（俯视 X-Z，离地 3–90cm 标障碍）→ **A\*** 规划 →
**差速轮** `(v,ω)` 控制（含 `a_max=0.5 m/s²`、`ω_max=1.2 rad/s` 底盘限幅，**指令物理可执行**）
→ **速度障碍法（VO）** 动态避障。

### 2.4 端侧（`M8`）
把「输入分辨率 / 特征数 / 算子」当算力旋钮，实测三维表（延迟 / 精度 / 算力预算）：
本机缩预算模拟得出 **0.5× ORB1000** 为最佳性价比点（延迟 82ms、ATE 0.363m）；
越过「特征地板 / 分辨率悬崖」VO 直接初始化失败而非精度平滑下降。

## 3. 直白讲解（建立直觉）

- **传统 VO 像『靠肉眼认路的人』**：灯一暗、手一抖就认不出地标、原地转圈。
- **VGGT 像『自带三维地图的导航仪』**：直接端到端估出「你走过的路」，**不依赖逐帧认地标**，所以暗处也稳。
- **融合兜底 = 保底伞**：平时用便宜的传统 VO；一旦诊断出它「晕了」，立刻切 VGGT，保证机器人始终知道自己在哪。
- **感知→控制 = 闭眼走路的人**：相机/深度是眼睛（感知），占据栅格是脑里「哪能走」，A\* 选安全路，`v/ω` 是迈腿动作。

                  │ 退化→塌缩?             <5%→告警     │

              深度(真值/真LiDAR) → 2.5D 占据栅格 → A* 规划 → 差速轮(v,ω) → 速度障碍法避障

## 9. 诚实边界（必读）

- **数据性质**：TUM `fr1/desk` 是**手持桌面基准**，非真机器人数据；用于演示算法链路与接口。
  真实机器人把输入换成板载 RGB-D + 轮速计 + 可选 LiDAR 即可（管线不变）。
- **退化是合成施加**：弱光 / 运动模糊为在带真值数据上可控施加，已明确标注；
  **真实恶劣环境证据**见 `M5 §4.2`（4Seasons 夜间）与 `D1_real_world`（水下 / 夜间语义）。
- **闭环是运动学仿真**：A\* / 差速控制为算法仿真，未接真实底盘；动态行人为「已知匀速横穿」模拟
  （聚焦避障逻辑本身），真实系统来自 M7 检测 + 跟踪 + 预测。
- **VGGT 尺度靠对齐、无语义**：几何兜底可靠，语义须接 `M7` 域专用封闭集模型（非开放词汇 VLM）。
- **闭环输入是室内手持数据**：本项目的"感知→规划→控制"闭环跑在 TUM `fr1/desk`（室内桌面）上。
  想看**同一套闭环接真实驾驶数据**（真实车载 RGB + 真实 LiDAR），见 **`P5 真实驾驶端到端闭环`**——
  它复用 `P4` 的真实驾驶建图，跑出 占据栅格→inflation→A\*→差速轮→VO 避障（P3 与 P5 是同一套规划/控制方法在不同数据上的落地）。
