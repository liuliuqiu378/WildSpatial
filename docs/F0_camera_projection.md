## 0. 一句话定位

**所有 3D 视觉，本质都是同一件事：把「一张 2D 照片里的像素」和「真实世界里的一个 3D 点」对上号。** 而"对上号"靠两本账：相机**内参**（它自己的眼睛长啥样）和**外参**（它站在哪、朝哪看）。本章就把这两本账讲透。

---

## 1. 目的：为什么必须先懂相机，才能谈"感知场景"

你做深度学习时，图片对你来说就是一个张量 `H×W×3`。但在 3D 视觉里，**图片不是终点，是"通往 3D 的入口"**。

- 你想知道"前方 3 米那个物体距我多远" → 必须先知道相机怎么把 3 米映射成图上几个像素。
- 你想把神经网络预测的"2D 框"变成机器人能抓的"3D 坐标"（这正是 `M7` 语义层干的事）→ 必须靠内参反投影。
- 你想让两台相机/前后两帧对上同一个 3D 点 → 必须知道各自的外参。

**不懂相机，你手里的 2D 模型就永远落不到真实世界里。** 这就是本章的目的。

---

## 2. 方法原理（专业，但只列骨架）

### 2.1 针孔相机模型
真实相机（忽略镜片畸变时）可用**针孔模型**近似：世界里的 3D 点，经过一个小孔，落在成像平面上，像倒立的。

设相机坐标系下一点为 $\mathbf{P}_c=(X,Y,Z)^\top$（$Z$ 为"向前"的深度），则它在成像平面上的坐标为：
$$x = f\frac{X}{Z},\quad y = f\frac{Y}{Z}$$
其中 $f$ 是焦距。这就是"近大远小"的数学表达：**深度 $Z$ 越大，像越小**。

### 2.2 内参矩阵 $K$
像素不是以"米"计的连续坐标，而是离散的、有主点的。统一写成：
$$
\begin{bmatrix}u\\v\\1\end{bmatrix}
= K\,[R\mid t]\,
\begin{bmatrix}X_w\\Y_w\\Z_w\\1\end{bmatrix},
\quad
K=\begin{bmatrix}f_x&0&c_x\\0&f_y&c_y\\0&0&1\end{bmatrix}
$$
- $f_x,f_y$：焦距（像素单位，含像素尺寸缩放）
- $c_x,c_y$：**主点**，图像中心大致位置
- $[R\mid t]$：**外参**，把世界坐标转到相机坐标（旋转 $R$ + 平移 $t$）

### 2.3 坐标帧（最常被忽视、最致命的概念）
同一只猫，在"猫自己坐标系""相机坐标系""房间坐标系"里的坐标**完全不同**。3D 视觉里一切混乱都源于"搞混了帧"。三个最常出现的帧：
- **世界帧 (world)**：固定不动的参考系（房间一角）。
- **相机帧 (camera)**：原点在相机光心，$Z$ 轴朝前。
- **图像帧 (pixel)**：即 $(u,v)$ 像素坐标。

> 记住一句话：**"点的位置"没有意义，必须说"在哪个帧下"。** 这和你写代码时变量有"作用域"是一个道理。

> **⚠️ 初学者常漏（F0 最容易栽的 3 个点）**：
> 1. **坐标帧混用**：把"相机系坐标"直接当"世界系"用 → 物体凭空飞走。任何坐标先问"它在哪个帧？"（见 §2.3）。
> 2. **把 $Z$ 当成"到相机的距离"**：$Z$ 是沿视线方向（光轴）的深度，**不是**到相机光心的欧氏距离；斜距 = $\sqrt{X^2+Y^2+Z^2}$。算"离我多远"要用斜距，不是 $Z$。
> 3. **以为标定一次永久有效**：震动、温度会让外参慢慢漂（见 `F9 §9.1`）；真机要定期重标，否则融合精度逐月下降。

### 2.4 畸变（真实相机逃不掉）
针孔模型是理想。真实镜片会"鼓"或"歪"，用径向 $(k_1,k_2)$ + 切向 $(p_1,p_2)$ 畸变系数修正（OpenCV/Brown 模型，见 §4）。广角/鱼眼相机必须用专门模型，不能硬套针孔。

## 3. 直白讲解（大白话 + 类比）

- **针孔模型 = 纸箱扎孔看外面**。纸箱壁是小孔，外面世界的"光锥"穿过小孔投到箱内壁。离箱壁越远的东西，投出来的像越小 → 这就是 $1/Z$。
- **内参 $K$ = 相机的"身份证 + 视力表"**。$f_x,f_y$ 说它眼睛多"长"（放大倍率），$c_x,c_y$ 说它的"视线中心"偏哪。换一台相机，$K$ 就变，同一 3D 点投到不同像素。
- **外参 $[R\mid t]$ = 相机"站在哪、看向哪"**。世界里的桌子不动，但你走到左边、蹲下、转头，桌子在你眼里的位置全变了——$R,t$ 就是描述你这个"位移+转向"。
- **坐标帧 = 同一只猫在不同人眼里的位置**。你说"猫在你左边 2 米"，是相对"你"这个帧；换成"房间"这个帧，可能是"东墙边 3 米"。做 3D 视觉第一件事：先问"这个坐标是在哪个帧？"
- **畸变 = 哈哈镜**。边缘被拉胖/压扁，所以算法得先"掰回直的"再算几何。

## 4. 真实知识 / 验证（领域标准，非本项目实测新数）

以下均为**可验证的领域常识**，不是本项目新测的数字：

1. **针孔 + Brown 畸变是工业事实标准**：OpenCV `calibrateCamera`、ROS `camera_calibration`、COLMAP 标定全用这一套。绝大多数消费相机可用针孔近似；鱼眼需 `fisheye` 模型。
2. **可跑的小实验（你本地就能验证，无需真机）**：下面这段 numpy 就是"投影 + 反投影"闭环，结果应**精确还原**原 3D 点——这本身就是"相机模型自洽"的最硬验证。

```python
import numpy as np
# 内参：以一台普通 RGB-D 相机为例（单位：像素）
K = np.array([[525., 0., 320.],
              [0., 525., 240.],
              [0.,   0.,   1.]])      # fx, fy, cx, cy
# 世界系下一点（米）：X 右、Y 下、Z 前
P_w = np.array([0.5, -0.3, 2.0, 1.0])
# 假设相机就在世界原点、无旋转：外参 = 单位阵
T_cw = np.eye(4)
P_c = (T_cw @ P_w)[:3]                 # 相机系坐标
# ① 投影：3D → 像素
u, v, w = (K @ P_c)
u, v = u/w, v/w
print(round(u,2), round(v,2))          # ≈ 452.5, 161.25
# ② 反投影：像素 + 深度 Z → 回到相机系 3D
Z = P_c[2]
X = (u - K[0,2]) * Z / K[0,0]
Y = (v - K[1,2]) * Z / K[1,1]
print(round(X,2), round(Y,2), round(Z,2))   # ≈ 0.5, -0.3, 2.0  ✅ 还原
```

## 6. 🏭 实际应用：相机模型不是教科书玩具

- **相机标定**：工厂/实验室用棋盘格算出 $K$ 和畸变，是机器人、AR、自动驾驶的出厂必做项。标不准，$1$ 厘米误差会放大成米级。
- **AR 贴图**：把虚拟沙发"稳稳放"在真实地板，靠的就是实时估计相机外参 + 内参投影。
- **机器人手眼标定**：机械臂"眼睛"（相机）和"手"（基座）的相对位姿，本质就是一组外参。
- **消费级 3D 重建**：你手机扫码测距、iPhone LiDAR，全在实时跑这套投影/反投影。

> **本项目对应**：`src/wildspatial/geometry/camera.py` 手搓了投影/反投影；`M1` 的 VO 就是在逐帧估外参。学完本章，你再看 `M1` 代码会恍然大悟："哦，它在算 $R,t$"。
