## 1. 目的：别从零开始，先把旧技能"挂载"上来

很多人怕入 3D 视觉，是因为被满屏公式吓退。但你有 **CNN/Transformer/损失设计/反向传播/数据管线** 的底子——这套在 3D 视觉里**直接有用**，而且越来越重要。本章帮你做一张"能力映射表"，让你知道：
- 哪些模块你**上手就能写**（深度回归、匹配、光流、分割）；
- 哪些是**全新的、必须补的**（投影几何、BA、坐标帧、TSDF）；
- 整体**心智模型**该是什么（神经网络预测 + 几何约束提拉到 3D）。

## 3. 必须新补的"几何三件套"（F0–F3 已铺垫）

你不需要先啃完李群才动手，但有三个概念绕不开，建议按此顺序补：

1. **坐标帧与投影**（`F0`）：同一 3D 点在不同帧坐标不同；内参 $K$、外参 $[R|t]$、投影/反投影公式。这是"把 2D 模型结果提拉成 3D"的唯一钥匙。
2. **多视图几何直觉**（`M0` 直觉部分）：对极几何（"左图一个点，在右图只能落在一条约定的线上"）、三角化（双目定位）。`M0` 的 6 张教学图就是可视化这些。
3. **融合与表示**（`F1`/`M2`）：多帧深度怎么融成 TSDF 网格；点云/网格/体素/NeRF 怎么选。

> 关键心态：**几何不是来"替代"你的神经网络的，是用来"约束"它的**。比如训练单目深度时，加一个"重投影一致性损失"，就是让几何规律替你当免费老师（无需真值标签）。

## 4. 直白讲解：整体心智模型

把 3D 视觉想象成 **"神经网络负责猜，几何负责较真"**：

- **神经网络**像一位经验丰富的画师，看一眼图就"猜"出哪近哪远、哪跟哪是同一物体（你的强项区）。
- **几何**像一位严谨的监理，拿着尺子（投影公式、重投影误差）检查："你猜的这个点，投回图像对得上吗？对不上就改。"

两者合力，才既快又准。**最前沿的 VGGT 类模型（`M4`）就是把"监理"也学进网络里了**——一次前向同时出深度+位姿+点云，但代价是黑箱、尺度需对齐、无语义。所以传统几何 pipeline（`M1/M2`）仍是不可替代的"地基 + 可解释兜底"。
